🔎 Lost Certificate

If your original certificate or mark sheet is lost, you must apply separately for a duplicate.

Application steps

  1. File a General Diary (GD) at the police station.
  2. Publish a notice of loss in a newspaper, if required.
  3. Submit the application with the required documents.
  4. Collect it as instructed when it is ready.

Documents required

  • Copy of the GD
  • Registration and admit cards
  • Copy of NID
Fee: Check the latest fee before applying  ·  Time: Varies
